# REDES
Diseñar redes no es solo conectar dispositivos; es construir el sistema nervioso de una organización
# 🏢 Proyectos de Redes - Cisco Packet Tracer

## 📋 Descripción
Repositorio con proyectos de diseño e implementación de redes utilizando **Cisco Packet Tracer**. Incluye configuraciones de VLANs, routing inter-VLAN, DHCP, NAT, ACLs y más.

## 📂 Proyectos

### 🏨 Proyecto Hotelero (CCNA)
Red para un hotel con múltiples áreas, VLANs y servicios centralizados.

### 🏢 PYME - CCNA
Red corporativa para PYME con 6 VLANs, Router-on-a-Stick y seguridad mediante ACLs.

### 🧪 Proyecto Práctica
Ejercicios y laboratorios para practicar conceptos de CCNA.

## 🛠️ Tecnologías Utilizadas
- Cisco Packet Tracer
- VLANs, Trunking (802.1Q)
- Router-on-a-Stick
- DHCP, DNS, HTTP
- ACLs, NAT
